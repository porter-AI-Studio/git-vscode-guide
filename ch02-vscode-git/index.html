VSCode 與 Git 整合操作

VSCode 內建了強大的 Git 視覺化支援，讓你不需要死記一堆終端機指令，也能輕鬆完成大部分的版本控制工作。以下是日常最常用的功能與面板介紹。

VSCode 內建 Source Control 面板

在 VSCode 左側欄位的第三個圖示 (長得像一個分支的圖示)，就是 原始檔控制 (Source Control) 面板。
它整合了 Git 的大部分功能，讓我們可以不用打指令就能輕鬆進行版本控制。

基本操作指南

1. 初始化 Git (Initialize Repository)

  • 若這是一個新專案，點擊 Source Control 面板上的 Initialize Repository 按鈕。
  • 這樣就會在當前資料夾建立一個隱藏的 .git 資料夾，開始追蹤檔案。

2. 查看變更 (Diff)

  • 在 Source Control 面板中，會列出所有被修改 (M)、新增 (U Untracked) 或刪除 (D) 的檔案。
  • 點擊檔案名稱，VSCode 會開啟左右對照的畫面，清楚標示哪裡新增了綠色，哪裡刪除了紅色。

3. 暫存變更 (Stage Changes)

  • 滑鼠移到檔案名稱上，點擊 + (Stage Changes) 按鈕，這會將檔案放入「暫存區」(Staged Changes)。
  • 也可以點擊 Changes 旁邊的 +，一次暫存所有變更。
  • 等同於指令：git add <檔案>。

4. 提交修改 (Commit)

  • 在面板上方的訊息框中輸入 Commit Message (提交訊息)，簡述這次改了什麼。
    • 建議使用標準前綴（例如 feat: 新增首頁設計 或 fix: 修正按鈕對齊問題）。
  • 點擊上方的 ✓ (Commit) 按鈕。
  • 等同於指令：git commit -m "你的訊息"。

5. 發佈到 GitHub (Publish to GitHub)

  • 若專案還沒上傳到 GitHub，可以在面板找到 Publish to GitHub 按鈕。
  • 選擇設定為 Public (公開) 或 Private (私人) 儲存庫，VSCode 會自動幫你在 GitHub 建立 Repo 並上傳所有程式碼。
