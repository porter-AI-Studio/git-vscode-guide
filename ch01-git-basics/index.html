Git 基本觀念

Git 是一套分散式版本控制系統，就像是程式碼的「時光機」。它可以幫助你紀錄每一次檔案的修改，讓你在需要時可以隨時回到過去的狀態。更重要的是，它讓多人協作開發變得井然有序，不會互相覆蓋彼此的程式碼。

核心名詞介紹

  • Repository (儲存庫 / Repo)：專案的資料夾，裡面包含了所有的檔案與 Git 的歷史紀錄。分為「本地 (Local)」與「遠端 (Remote)」。
  • Commit (提交)：一個版本的紀錄。就像是拍了一張快照，記錄了當下檔案的狀態。每個 Commit 都需要有說明訊息 (Commit Message)。
  • Branch (分支)：基於某個 Commit 切分出來的平行宇宙。可以讓你獨立開發新功能，而不會影響到主程式 (通常稱為 main 或 master)。
  • Merge (合併)：將不同分支的修改整併在一起。
  • Clone (複製)：將遠端儲存庫完整下載到本地電腦。
  • Remote (遠端儲存庫)：存放在網路上的儲存庫，如 GitHub 或 GitLab。
  • Push (推上遠端)：將本地的 Commit 上傳到遠端儲存庫。
  • Pull / Fetch (拉取最新進度)：從遠端儲存庫下載最新的 Commit 紀錄。

Git 狀態的三個區域

理解 Git 最重要的觀念就是檔案的「三階段狀態」：

  1. Working Directory (工作目錄)：你目前正在編輯的檔案狀態。
  2. Staging Area (暫存區)：你準備要提交 (Commit) 的檔案會先放到這裡。
  3. Local Repository (本地儲存庫)：正式提交後，歷史紀錄會保存在這裡。

本地與遠端儲存庫的關聯

在了解了本地的三個階段後，我們需要將這些變更與網路上的 遠端儲存庫 (Remote Repository) 進行同步。最常見的遠端平台就是 GitHub 或是 GitLab。

  • Clone (複製)：如果是第一次參與專案，你會使用 git clone 把遠端的程式碼完整下載到電腦中，成為你的「工作目錄」。
  • Push (推上遠端)：當你在本地儲存庫累積了幾個 Commit 後，需要使用 git push 將這些紀錄上傳到遠端儲存庫，讓其他人也能看到你的修改。
  • Pull / Fetch (拉取最新進度)：當遠端有其他人推送了新程式碼，你可以使用 git pull 將最新進度下載回你的本地端。
